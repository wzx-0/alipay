# fd-detail-page：详情页模板化快速产出

本 Skill 是 `seehoo-dev-fe-guide` 的辅助 Skill，为详情页场景提供模板化快速产出能力。

> **重要**：本 Skill 是辅助 Skill，提供模板参考，不替代核心 Skill `seehoo-dev-fe-guide` 的规范约束。调用本 Skill 前必须已加载核心 Skill 对应子规范，所有产出必须同时满足核心 Skill 规范。

## 详情页标准结构

详情页由两个区域组成：

### 1. 信息展示区（Info Section）

- 位置：页面主体
- 内容：业务数据的字段展示
- 组织方式：按业务语义分组（如基础信息组、状态信息组、关联信息组）
- 每个字段：标签 + 值，值的格式由字段类型决定（文本直接展示、枚举映射中文、日期格式化）
- 业务编码清单中的枚举字段，必须使用映射展示（中文标签而非原始编码）

### 2. 操作区（Action Section）

- 位置：页面顶部或底部
- 内容：业务操作按钮组（编辑、返回、审批、删除等）
- 交互：按钮点击触发对应的业务流程（跳转编辑页、调用 API、返回列表页等）
- 操作按钮的显示/隐藏可受状态字段控制（如"已审批"状态隐藏"审批"按钮）

## 字段展示配置模式

- 字段列表与 FRD-前端中的详情页字段清单对齐，不得增减字段
- 每个字段配置包含：字段名、显示标签、格式化方式（文本/枚举映射/日期/金额等）
- 字段分组配置：组标题 + 组内字段列表
- 布局方式遵循骨架 UI 库的描述列表/表单展示方案

## 与核心 Skill 的配合

使用本 Skill 时，所有实际代码产出仍需满足：
- `common.md`：命名、目录、基座约束
- `component-layer.md`：组件职责边界、样式规范
- `page-layer.md`：页面组装原则

本 Skill 提供的模板仅作为结构参考，具体实现细节（组件拆分方式、样式方案、技术选型）由核心 Skill 和项目骨架决定。
