# fd-filter-table：列表页模板化快速产出

本 Skill 是 `seehoo-dev-fe-guide` 的辅助 Skill，为列表页场景提供模板化快速产出能力。

> **重要**：本 Skill 是辅助 Skill，提供模板参考，不替代核心 Skill `seehoo-dev-fe-guide` 的规范约束。调用本 Skill 前必须已加载核心 Skill 对应子规范，所有产出必须同时满足核心 Skill 规范。

## 列表页标准结构

列表页由三个区域垂直排列组成：

### 1. 搜索区（Filter Section）

- 位置：页面顶部
- 内容：业务筛选条件表单
- 交互：填写筛选条件 → 点击查询按钮 → 触发表格数据刷新
- 常见字段类型：下拉选择（枚举字段）、文本输入、日期范围选择
- 清空按钮：一键重置所有筛选条件

### 2. 表格区（Table Section）

- 位置：搜索区下方
- 内容：数据表格，列与 FRD-前端中的表格列清单对齐
- 操作列：右侧固定，包含编辑、删除等业务操作按钮
- 数据源：通过 props 或 Store 获取列表数据

### 3. 分页区（Pagination Section）

- 位置：表格区下方
- 内容：分页控件（页码、每页条数选择）
- 交互：切换页码/条数 → 触发带分页参数的 API 重新请求

## 筛选条件配置模式

- 篮选字段与 FRD-前端中的搜索表单字段清单对齐
- 每个筛选项对应一个表单控件，控件类型由字段类型决定（枚举→下拉，文本→输入框，日期→日期选择器）
- 篮选表单的布局遵循骨架 UI 库的表单布局方案（行内 / 网格 / 等）

## 表格列定义模式

- 表格列数组配置，每列包含：字段名、列标题、宽度、对齐方式
- 业务编码清单中的枚举字段，在表格中使用映射渲染（显示中文标签而非原始编码）
- 操作列配置：按钮组，通过事件回调通知父组件

## 与核心 Skill 的配合

使用本 Skill 时，所有实际代码产出仍需满足：
- `common.md`：命名、目录、基座约束
- `component-layer.md`：组件职责边界、样式规范
- `page-layer.md`：页面组装原则

本 Skill 提供的模板仅作为结构参考，具体实现细节（组件拆分方式、样式方案、技术选型）由核心 Skill 和项目骨架决定。
