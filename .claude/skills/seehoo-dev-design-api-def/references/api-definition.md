## 字段填写规则

**字段类型**：只用 `String` / `Number` / `Bool` / `Array` / `Object`

**是否必填**：`Y` 必填 / `N` 非必填 / `C` 条件必填（在备注列说明条件）

**值约束**：无约束留空，禁止填"无"或"-"；写法示例：
- 长度：`长度：1-50字符`
- 格式：`格式：UUID` / `格式：手机号11位`
- 枚举：`枚举：PENDING/APPROVED/REJECTED`
- 精度：`精度：2位小数`
- 字典：`字典：{字典编码}`

**嵌套对象**：在同一表格中用 `··fieldName` 缩进表示子字段，不新建子表
