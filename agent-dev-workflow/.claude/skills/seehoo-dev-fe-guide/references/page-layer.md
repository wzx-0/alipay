# page-layer.md：页面层规范

## 页面组装原则

### 页面是组件容器

Page 组件的职责是组装 View 和 UI 组件，提供页面级布局。Page 组件本身不包含业务逻辑：

- 不在 Page 内直接编写表单校验、数据转换等逻辑
- 不在 Page 内直接调用 API 封装函数（数据获取通过 Store 或子组件处理）
- Page 内的业务逻辑仅限于页面级编排（如弹窗开关、Tab 切换等页面状态）

### 页面与组件关系

- Page 通过 props 向 View 组件传递数据
- Page 通过事件回调接收 View 组件的操作通知（如表单提交成功 → 关闭弹窗）
- Page 通过 Store 获取跨组件共享数据

## 布局规范

### 原则

- 页面布局使用骨架已有的布局组件和布局方案
- 响应式规则遵循骨架既定的响应式断点
- 不自行创建与骨架布局组件功能重叠的新布局组件

### 常见页面类型布局

- **列表页**：搜索区 + 表格区 + 分页，垂直排列
- **详情页**：信息展示区 + 操作区，按业务语义分组
- **表单页**：表单区 + 操作按钮区，垂直排列

## 路由挂载

### 原则

- 每个页面组件对应一个路由项
- 路由配置在 api-layer 规范中定义（路由配置属于基础层），页面组件在路由中引用
- 新增页面的路由挂载方式遵循骨架已有的路由注册模式
- 路由 meta 信息与骨架已有的约定对齐（权限、标题、缓存等）
