### Step1 - 自动交叉检查

- **输入**：FRD-前后端、API 清单、业务编码清单、API 定义、DDL 脚本
- **产出**：交叉检查结论，写入评审报告
- **检查项**：

| # | 检查项 | 方法 | 通过标准 |
|---|--------|------|----------|
| 1 | API清单 ↔ API定义 | 逐条比对 API 清单 vs API 定义 | API 清单中每个接口在 API 定义中都有详细定义；API 定义中无 API 清单中不存在的"孤儿"接口 |
| 2 | API ↔ DDL 字段 | 逐接口比对请求/响应字段 vs DDL 表字段 | 每个持久化字段在 DDL 中有对应列；DDL 中无 API 中不使用的冗余列 |
| 3 | 业务编码清单 ↔ 设计产物 | 字典编码/枚举/常量在 API 定义和 DDL 中的使用情况 | 编码清单中每项在 API 或 DDL 中有引用；API/DDL 中使用的枚举值均在编码清单中定义 |

- **失败处理**：任一项发现偏差，记入评审报告"偏差清单"章节和 TODO 异常栏，但不阻塞 Step2
