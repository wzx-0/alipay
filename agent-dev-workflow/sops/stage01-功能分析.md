- **输入**：FRD-后端初稿

### Step4 - 人工确认

- **产出**：人工确认结论
- **说明**：
    1. 主 Agent 完成 Step3 后，**主动列出 FRD 中所有待确认事项**，等待人工回复
    2. 回复格式：【OK】+ 各待确认项的答案
    3. 主 Agent 收到回复后，将答案更新进 FRD 对应章节，并清空待确认事项表格
    4. FRD、API 清单与业务编码清单更新完毕即为定稿，本步骤完成
