# REQ001 API 交互图说明

> 需求编号: REQ001
> 业务模块: 汽车订阅支付宝对接
> 文档版本: v1.0
> 生成日期: 2026-09-22
> 上游产物: `REQ001-API-Definition.md`（API 定义 v1.0）

## 一、说明

本文档为 REQ001 API 交互图（Mermaid 时序图，`.mmd`）的配套说明，包含参与者定义、文件索引与 API 覆盖矩阵。交互图仅描述前端与服务端的交互流程；服务端内部逻辑（含服务端调用支付宝 OpenAPI 的过程）以 `Note` 简述，详细流程见 API 逻辑图（`seeboo-dev-design-api-logic` 产物）。

## 二、参与者定义

| 缩写 | 名称 | 端类型 | 说明 |
| --- | --- | --- | --- |
| U | 管理端操作人员 | PC | 运营/审核/财务/售后等内部人员，通过管理后台 PC 页操作 |
| UM | 订阅用户 | 支付宝小程序 | C 端用户，通过商家支付宝小程序页面操作 |
| P_PC | 管理端 PC 页面 | PC | 商品管理、订单管理、审核、资金、售后等后台页面 |
| P_MINI | 订阅小程序页面 | 支付宝小程序 | 商家自建页面（商品/确认订单/订单详情页）及租赁快捷下单插件页的承载端 |
| S | 订阅服务端 | — | 汽车订阅后端服务，所有 API（A0101001~A0108001）的提供方 |
| AL | 支付宝平台 | — | 含芝麻免押受理台、支付宝收银台及开放平台异步通知；作为本需求对接的核心外部参与方出现 |

**端类型标注说明（需评审确认）**：交互图规范给出 H5/APP/WX/PC 四种前端端类型后缀。本需求前端承载为支付宝小程序（商家私域自建页 + 租赁快捷下单插件页），四种既有后缀均不适用，故扩展 `MINI` 后缀（`P_MINI`）表示支付宝小程序页面。

**支付宝平台参与方式说明**：`AL` 参与者仅出现在两类交互中——(1) 前端唤起支付宝侧页面（插件下单页、芝麻免押受理台、收银台）；(2) `[A0108001]` 支付宝异步通知。服务端主动调用支付宝 OpenAPI（创单、签约、支付、履约同步等）属于服务端外部调用，图中以 `Note` 标注，不直接绘制。
