# 汽车订阅接口文档（REQ001-支付宝对接）

> 版本：1.0　|　更新日期：2026-09-23　|　服务：rent-app　|　默认端口：18080
>
> 配套 Postman 集合：`docs/postman/汽车订阅接口.postman_collection.json`

---

## 1. 通用约定

### 1.1 基础信息

| 项目 | 说明 |
|------|------|
| 基础地址 | `http://localhost:18080`（部署后替换为实际域名） |
| 协议 | HTTP/1.1，业务接口全部为 **POST** |
| 请求格式 | `application/json`（回调接口除外，为 form 表单） |
| 字符编码 | UTF-8 |
| 时间格式 | `yyyy-MM-dd HH:mm:ss`（请求与响应一致） |

### 1.2 统一响应结构

所有业务接口返回如下结构（回调接口除外）：

```json
{
    "code": "SY000000",
    "message": "交易成功",
    "data": { },
    "success": true,
    "timestamp": "1790127201659"
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| code | String | 响应码，`SY000000` 表示成功 |
| message | String | 响应描述 |
| data | Object | 业务数据，失败时为 null |
| success | Boolean | 是否成功 |
| timestamp | String | 服务端毫秒时间戳 |

**序列化约定**：雪花 ID 等长整型统一序列化为 **String**（防前端精度丢失）；金额字段为字符串（元，2 位小数）。

### 1.3 错误码

| 错误码 | 说明 | 典型场景 |
|--------|------|----------|
| SY000000 | 交易成功 | — |
| RENT001 | 请求参数不合法 | 缺必填项、枚举值非法、期次不存在 |
| RENT002 | 订单不存在 | outOrderId 无对应订单 |
| RENT003 | 订单当前状态不允许该操作 | 状态机前置校验不通过、已完结/已关闭再关单 |
| RENT004 | 商品或SKU不存在 | goodsId/skuId 无对应记录 |
| RENT005 | 支付宝接口调用失败 | 网关错误/业务拒绝（message 携带 sub_code） |
| RENT006 | 支付宝通知验签失败 | 回调签名不合法 |
| RENT007 | 售后单不存在 | 预留 |
| SYS000 | 系统繁忙，请稍后重试 | 未归类系统异常 |

### 1.4 订单状态机

```
                    ┌───────────── 风控拒绝/取消（order.close，任意确认收货前状态）─────────────┐
                    │                                                                        ▼
CREATED ──冻结成功──▶ SIGNED ──审核通过──▶ APPROVED ──商家交车──▶ DELIVERED ──用户收车──▶ RECEIVED ──┐
  (创单)              ▲          (risk.audit=1)   (send)         (receive)                      │用户寄回
                    │                                                                          ▼
                    │                                                              RETURN_DELIVERED
                    │                                                                          │商家验收
                    └────────────────────────────────────────────────────────── RETURN_RECEIVED
                                                                                              │完结
                                                                                              ▼
                                                                                           FINISHED
```

| 状态 | 含义 |
|------|------|
| CREATED | 已创建（待签约/待审核） |
| SIGNED | 已签约（免押冻结成功，由异步通知推进） |
| APPROVED | 商家审核通过（风控 audit=1） |
| DELIVERED | 已交付（商家交车） |
| RECEIVED | 已收货（用户确认收车，订阅中） |
| RETURN_DELIVERED | 归还已寄出（用户寄回） |
| RETURN_RECEIVED | 归还已收货（商家验收） |
| FINISHED | 已完结（自动解冻 + 解除代扣） |
| CLOSED | 已关闭 |

## 3. 订单接口

### 3.1 创建租赁订单（A0102001）

`POST /api/v1/rent/order/create`

> 依赖支付宝网关（order.create）。创单失败时本地订单自动关闭留痕，返回 RENT005。

**请求参数**

| 字段 | 类型 | 必填 | 说明 |
|------|------|:----:|------|
| orderType | String | 是 | RENT-新租 / RELET-续订 / BUYOUT-买断 |
| sourceId | String | 是 | 前端 `my.checkBeforeAddOrder` 返回的 sourceId |
| buyerOpenId | String | 是 | 买家支付宝 openId |
| goodsId | String | RENT必填 | 商品ID（数字字符串） |
| skuId | String | RENT必填 | SKU ID（数字字符串） |
| quantity | Integer | RENT必填 | 购买数量 |
| originOrderId | String | RELET/BUYOUT必填 | 原订单的 outOrderId，商品明细自动取原订单快照 |
| depositPrice | String | RENT必填 | 押金金额（元），芝麻免押预授权冻结金额，需 >0 |
| freight | String | 否 | 运费（元） |
| additionalPrice | String | 否 | 增值服务费（元） |
| rentPlanInfo | Object | RENT必填 | 订阅计划 |
| rentPlanInfo.rentStartTime | String | 是 | 租赁开始时间 `yyyy-MM-dd HH:mm:ss` |
| rentPlanInfo.rentEndTime | String | 是 | 租赁结束时间 |
| rentPlanInfo.installments | List | 是 | 期次计划，最长 36 期 |
| rentPlanInfo.installments[].installmentNo | Integer | 是 | 期号，从 1 开始 |
| rentPlanInfo.installments[].installmentPrice | String | 是 | 当期订阅金额（元） |
| rentPlanInfo.installments[].planPayTime | String | 是 | 计划扣款时间 |
| rentPlanInfo.installments[].buyoutPrice | String | 否 | 到期购买金额（元），仅最后一期 |
| shopInfo | Object | 否 | 自提门店：shopName / shopAddress / shopTel |
| receiverInfo | Object | 否 | 收货人：receiverName / receiverTel / detailedAddress |
| merchantExtInfo | Object | 否 | 商家透传数据，原样透传支付宝 |

**请求示例（RENT）**

```json
{
    "orderType": "RENT",
    "sourceId": "SRC-TEST-001",
    "buyerOpenId": "OPENID-TEST-001",
    "goodsId": "2102572336484487001",
    "skuId": "2102572336484487002",
    "quantity": 1,
    "depositPrice": "5000",
    "freight": "50",
    "rentPlanInfo": {
        "rentStartTime": "2026-10-01 00:00:00",
        "rentEndTime": "2027-10-01 00:00:00",
        "installments": [
            {
                "installmentNo": 1,
                "installmentPrice": "1000",
                "planPayTime": "2026-11-01 00:00:00",
                "buyoutPrice": "90000"
            }
        ]
    },
    "shopInfo": {
        "shopName": "测试门店",
        "shopAddress": "测试市测试区测试路1号",
        "shopTel": "0755-12345678"
    },
    "receiverInfo": {
        "receiverName": "张三",
        "receiverTel": "13800138000",
        "detailedAddress": "测试市测试区测试路1号"
    }
}
```

**响应 data**

| 字段 | 类型 | 说明 |
|------|------|------|
| alipayOrderId | String | 支付宝订单 ID |
| outOrderId | String | 商家侧订单号（后续所有订单操作以此定位） |
| path | String | 订单详情页路径（前端跳转） |

**业务规则**
- 订单总价 = 运费 + 增值服务费 + Σ 各期订阅金额
- RELET/BUYOUT 的商品明细自动快照自原订单第一条明细，支付宝请求携带 `relet_info` / `buyout_info.origin_order_id`
- 支付宝创单失败 → 本地订单置 CLOSED（closeReasonDesc 记录失败原因）

## 5. 风控接口

### 5.1 风险咨询（A0103001）

`POST /api/v1/rent/risk/consult`

> 依赖支付宝网关（risk.consult，查综合风险）。每次调用落一条咨询留痕。

| 字段 | 类型 | 必填 | 说明 |
|------|------|:----:|------|
| outOrderId | String | 是 | 商家侧订单号 |

**响应 data**

| 字段 | 类型 | 说明 |
|------|------|------|
| riskLevel | String | 综合风险等级 T1~T10（T1-T4 低 / T5-T6 中 / T7-T10 高） |
| auditResult | String | 已有审核结论时返回：1-通过 2-拒绝 3-转人工 |
| consultResult | String | 风控咨询详情 JSON |

**审核策略口径**：T1-T4 自动通过 / T5-T6 转人工 / T7-T10 拒绝（由管理端执行）。

### 5.2 审核结论提交（A0103002）

`POST /api/v1/rent/risk/audit`

> 依赖支付宝网关。

| 字段 | 类型 | 必填 | 说明 |
|------|------|:----:|------|
| outOrderId | String | 是 | 商家侧订单号 |
| auditResult | String | 是 | 1-通过 / 2-拒绝 |
| rejectReason | String | auditResult=2 时必填 | 拒绝原因（否则 RENT001） |

**业务规则**
- 通过：调 fulfillment.approve，订单 CREATED → APPROVED
- 拒绝：调 order.close（reasonCode=3114），订单 → CLOSED，关闭原因记录 rejectReason

## 6. 支付接口

### 6.1 订单支付（A0104001）

`POST /api/v1/rent/order/pay`

> 依赖支付宝网关（order.pay）。支付结果以异步通知为最终确认。

**请求参数**

| 字段 | 类型 | 必填 | 说明 |
|------|------|:----:|------|
| outOrderId | String | 是 | 商家侧订单号 |
| payMethod | String | 是 | JSAPI-小程序收银台 / RENT_DEDUCT-周期代扣 / PRE_AUTH-预授权转支付 |
| payItems | List | 是 | 费项明细，不能为空 |
| payItems[].feeType | String | 是 | RENT-订阅金 / INDEMNITY-赔付违约金 |
| payItems[].installmentNo | Integer | feeType=RENT 必填 | 期号（期次置"支付中"，已支付期次不覆盖） |
| payItems[].payAmount | String | 是 | 本次支付金额（元） |
| payTimeoutExpress | String | 否 | 支付超时（如 15m，JSAPI 场景有效） |

**请求示例**

```json
{
    "outOrderId": "1940xxxxxP0001占位",
    "payMethod": "JSAPI",
    "payItems": [
        { "feeType": "RENT", "installmentNo": 1, "payAmount": "1000.00" }
    ],
    "payTimeoutExpress": "15m"
}
```

**响应 data**

| 字段 | 类型 | 说明 |
|------|------|------|
| tradeNo | String | 支付宝交易号（JSAPI 供前端 `my.tradePay` 唤起收银台） |
| outTradeNo | String | 商家侧支付单号 = outOrderId + "P" + 4位流水 |
| payAmount | String | 本次支付总金额 |

**业务规则**
- 同步返回 trade_no 且交易成功 → 流水直接置"成功"；否则置"处理中"，等异步通知确认
- 期次账单状态联动：待支付 → 支付中；支付成功通知后 → 已支付并累计已付金额

## 7. 回调接口（支付宝 → 本服务）

### 7.1 异步通知

`POST /api/v1/callback/alipay/notify`

> **注意：本接口返回纯文本 `success` / `fail`，不走统一 JSON 包装，且不抛异常。**
> freeze_notify_url 与 pay_notify_url 均指向此地址，须外网可达。

**请求格式**：`application/x-www-form-urlencoded`

| 关键参数 | 说明 |
|----------|------|
| notify_id | 通知ID，幂等去重键（缺失时按 biz_content 摘要生成） |
| msg_method | 消息类通知方法名（有值归类为 MESSAGE） |
| biz_content | 业务报文 JSON |
| sign / sign_type | RSA2 签名 |

**处理链路**

```
RSA2验签（排除sign/sign_type，key升序） ──失败──▶ 应答 fail（支付宝重试）
        │通过
        ▼
notify_id 幂等（重复通知复用已有记录，不再重复处理）
        │
        ▼
按报文分类分发：
  PAY（biz含trade_status）      → 更新支付流水状态 + 期次账单置已支付
  FUND_AUTH_FREEZE（含operation_status，FREEZE_SUCCESS）→ 签约表置已冻结/已签约，订单 CREATED → SIGNED
  MESSAGE（含msg_method）       → 落库留痕（售后/订单变更处理属后续阶段）
        │
        ▼
处理成功 process_status=1；处理失败（如无对应流水/订单）=2 并应答 success，等补偿任务重试
```

**通知报文示例（支付结果）**

```json
{
    "out_trade_no": "1940xxxxxP0001",
    "trade_status": "TRADE_SUCCESS",
    "trade_no": "20260923220014xxxxx"
}
```

**应答**：处理完成返回 `success`（纯文本）；验签失败返回 `fail`。

## 8. 联调注意事项

1. **支付宝配置**：`application.yml` 中 `app-id`、`app-private-key`、`alipay-public-key`、`zm-service-id`、`category-id` 为 TODO 占位，联调前必须替换（私钥为 PKCS8 一行 Base64，不含头尾标记与换行）。
2. **网关切换**：沙箱环境将 `alipay.rent.gateway` 改为 `https://openapi.alipaydev.com/gateway.do`，正式环境留空用默认网关。
3. **回调可达性**：本地联调需内网穿透，两个 notify_url 替换为穿透域名。
4. **响应验签**：联调期 `verify-response-sign: false` 可关闭，生产建议开启。
5. **幂等**：创单 outOrderId 全局唯一（服务端生成）；支付流水号防重；通知 notify_id 幂等。
6. **测试顺序建议**：创单 → 签约串 → 风控咨询/审核 → 支付 → （冻结通知到达）→ 发货 → 收货 → 完结，每步后用订单详情核对状态流转。
